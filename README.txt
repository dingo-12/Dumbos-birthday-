DUMBO BIRTHDAY WEBSITE — UPDATED VERSION

HOW TO PREVIEW ON YOUR ANDROID TABLET
1. Extract this ZIP.
2. Open the dumbo_birthday_site_updated folder in Acode.
3. Open index.html and use Acode's Preview / Run in browser option.
4. Keep the assets folder beside index.html, style.css, script.js and cake.html.
5. The cake page is cake.html; the present scratch effect unlocks its button.

PUBLISHING LATER WITH GITHUB PAGES
When the site is tested and you're happy with it, create a GitHub repository, upload the contents of this folder (not the ZIP itself), then enable GitHub Pages from Settings > Pages > Deploy from a branch > main > /(root).
A public GitHub Pages site can be viewed by anyone with its link. Keep private details out of public pages.
